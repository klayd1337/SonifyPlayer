## 📖 О проекте

**Yandex Music Desktop Player** — это красивый и функциональный музыкальный плеер для настольных компьютеров, который объединяет мощь Яндекс.Музыки с современным дизайном и продвинутыми возможностями воспроизведения.

Плеер построен на связке **Electron** (клиентская часть) и **FastAPI** (прокси-сервер), что позволяет обходить ограничения браузера, обеспечивать плавное воспроизведение и работать с неофициальным API Яндекс.Музыки напрямую.

Проект создавался как альтернатива официальному веб-плееру — с более гибкими настройками, кастомным интерфейсом и уникальными функциями, которых нет в оригинале.

## ✨ Ключевые особенности

### 🎧 Воспроизведение
- Потоковое воспроизведение треков из Яндекс.Музыки в высоком качестве
- **Бесконечная «Моя волна»** — умная подгрузка следующих треков без задержек
- Загрузка треков из «Мне нравится», чартов и плейлистов
- Поиск по всей библиотеке Яндекс.Музыки
- Плавное переключение между треками с фоновой предзагрузкой

### 🎨 Интерфейс
- **Тёмная и светлая темы** — переключение одним кликом
- **Настраиваемая прозрачность окна** — от полностью непрозрачного до почти стеклянного (0–100%)
- **Визуализатор музыки** — три режима отображения (столбцы, волна, круг) с регулируемой чувствительностью
- **Всплывающий слайдер громкости** — появляется по клику на иконку динамика
- **Интерактивный прогресс-бар** — перемотка кликом в любую точку трека
- **Красивые уведомления** — информируют о событиях без прерывания воспроизведения

### ⌨️ Управление
- **Горячие клавиши** для всех ключевых действий:
  - `Space` — воспроизведение / пауза
  - `↑` / `↓` — регулировка громкости
  - `Ctrl+Shift+S` — открыть настройки
  - `Ctrl+Shift+L` — загрузить «Мне нравится»
- **Индикатор радио-режима** — показывает, что включена бесконечная волна
- **Быстрая загрузка** любимых треков одной кнопкой

### ⚙️ Настройки
- Выбор темы оформления (тёмная / светлая)
- Управление прозрачностью окна
- Включение и настройка визуализатора
- Переключение между обычной и бесконечной «Моей волной»
- Все настройки сохраняются в `localStorage` и восстанавливаются при запуске

---

**Зачем нужен прокси-сервер?**

Браузер (и Electron) не может напрямую обращаться к API Яндекс.Музыки из-за:
- CORS-политики
- Необходимости авторизации по токену
- Сложной структуры ответов API

FastAPI-сервер берёт на себя всю «грязную работу»: авторизацию, преобразование данных, извлечение прямых ссылок на аудио и кэширование. Клиент получает чистый JSON и просто играет музыку.

### Требования
- Node.js 16+
- Python 3.9+
- Токен Яндекс.Музыки ([как получить](https://github.com/MarshalX/yandex-music-api#получение-token))

### Установка

```bash
# 1. Клонируем репозиторий
git clone https://github.com/yourusername/yandex-music-player.git
cd yandex-music-player

# 2. Устанавливаем Node.js зависимости
npm install

# 3. Устанавливаем Python зависимости
cd backend
pip install -r requirements.txt

# 4. Настраиваем токен
# Создаём файл backend/config.py:
echo 'YANDEX_MUSIC_TOKEN = "ваш_токен_здесь"' > config.py
```

### Терминал 1
```bash
cd backend
uvicorn api_server:app --host 0.0.0.0 --port 3000 --reload
```

### Терминал 2
```bash
npm start
```
